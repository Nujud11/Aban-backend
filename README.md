# Aban — ADOS Score Prediction (Backend)

Aban is My graduation project that predicts ADOS scores for Autism Spectrum Disorder (ASD) assessment using sequential behavioral signals such as eye-gaze and upper-body movement data.

This repository contains the **Flask backend** that loads a trained deep learning model and serves predictions to a web interface.

## Project Repositories
- Backend (this repo)
- Frontend (GitHub Pages): https://github.com/Nujud11/aban-website
